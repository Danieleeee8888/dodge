  DODGE — perché su iPhone "non va" e come sistemare (senza impazzire)
================================================================================

IL PROBLEMA VERo
----------------
• Se mandi il FILE index.html su WhatsApp / Telegram / Mail, spesso l’iPhone lo
  apre in ANTEPRIMA o in un lettore che NON esegue JavaScript → schermo nero,
  menu che non risponde, o pagina "vuota".
• Non è (solo) colpa del codice: è così che iOS tratta i file .html allegati.

COSA DEVI FARE (una tantum)
----------------------------
Metti il gioco su Internet con indirizzo HTTPS e manda agli amici SOLO QUEL LINK.

Opzione A — Netlify Drop (la più veloce, ~1 minuto)
  1. Vai su https://app.netlify.com/drop
  2. Trascina nella pagina TUTTA la cartella che contiene index.html
     (o solo index.html se è l’unico file che ti serve).
  3. Netlify ti dà un indirizzo tipo https://nome-a-caso-123.netlify.app
  4. Copia quel link e mandalo su WhatsApp. Gli amici lo aprono → Safari o
     Chrome dall’interno della chat (⋯ → Apri in Safari).

Opzione B — GitHub Pages
  1. Crea un repository su GitHub, carica index.html nella root.
  2. Impostazioni → Pages → Branch "main", cartella / (root).
  3. Il sito sarà https://TUOUSER.github.io/NOMEREPO/

Opzione C — Prova in casa (stessa Wi‑Fi)
  Dal PC nella cartella del gioco:
    python -m http.server 8080
  Sul telefono apri http://IP-DEL-PC:8080
  (solo test; dagli amici serve comunque un hosting come A o B).

DOPO CHE HAI IL LINK HTTPS
---------------------------
• Agli amici: "Apri il link, se si apre dentro WhatsApp tocca ⋯ e Apri in Safari".
• Non rinviare il file .html come allegato: usa sempre il link.

Se ancora non parte
--------------------
• Aggiorna iOS.
• Prova da Safari diretto (non in-app).
• Se compare un messaggio rosso sotto al titolo DODGE, segnala quel testo.
